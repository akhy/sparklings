# StructDiff

Configurable JSON/YAML Diff Tool for comparing structured data with advanced configuration options.

## Features (Planned)

- Multi-format support: JSON, YAML, TOML
- Side-by-side and unified diff views
- Advanced normalization options
- Path-based ignore rules
- Embedded string parsing (e.g., K8s ConfigMaps)
- Preset system with built-in and custom presets
- LocalStorage persistence
- Import/export configuration

## Development

```bash
# Install dependencies
pnpm install

# Run dev server (http://localhost:5176)
pnpm dev

# Build
pnpm build

# Deploy to Cloudflare Pages
pnpm deploy
```
