# Agent Rules for Sparklings Monorepo

## Git Commit Policy
All commits generated by agents must strictly follow these rules:
- **Exactly one scope conventional commit:** Always format commits as `type(scope): subject`.
- **Short commit subject first line:** Keep the first line under 50 characters if possible, and no more than 72.
- **Explain "Why", not "How":** In the commit description body, explain the rationale behind the change (why it is needed), rather than detailing the code changes themselves (which are visible in the diff).

## Package Manager & Workspaces
- **Bun is the package manager:** This monorepo uses Bun (v1.3+). Do not use pnpm or npm commands, and do not introduce `pnpm-workspace.yaml` or `pnpm-lock.yaml`.
- **Root-level Workspace & Catalogs:** Workspace configurations and dependency catalogs are defined directly in the root `package.json` under `"workspaces"` and `"catalog"` objects.
- **Turborepo Execution:** Monorepo tasks are orchestrated via Turborepo (`turbo.json`).

## Running Tests
- **Non-Watch Mode:** To run vitest suites a single time, append the run flag: `bun run test -- --run` or use the coverage script `bun run test:coverage`. Do not run `bun run test` on its own in background tasks as it defaults to watch mode and will hang.
